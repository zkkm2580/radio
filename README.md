# RadioPlayer（安卓车机收音机）

功能：
- 内置播放在线直播列表，开机自动拉取并显示条目（离线时显示上次缓存）
- 支持车机 / 方向盘上下键切换条目，确认键或点击播放
- 夜间模式跟随系统深色模式自动切换
- 点击即播（无单独播放界面），息屏持续后台播放
- 横屏 / 大按钮 / 车机适配
- 仍可手动输入流媒体 URL，或导入 M3U 播放列表

## 播放列表

启动时自动拉取并更新内置列表（HTTPS）：

    https://zj.537224.xyz/radio.txt

列表支持三种写法混排，识别后按 URL 自动去重：

```
#EXTINF:-1 group-title="电台",中国之声        ← M3U 写法（上一行是台名）
http://example.com/cnr.m3u8                  ← 纯 URL（台名自动推断）
江苏经典流行音乐广播,https://lzlive.vojs.cn/2wtSfrS/92/live.m3u8   ← 名称,URL
```

离线行为：首次拉取成功后会把原始列表缓存到本地，之后每次冷启动先渲染缓存，
让你一上车就能看到频道，再后台静默更新；拉取失败会在状态栏提示并保持旧列表。

## 车机按键

| 按键 | 行为 |
| --- | --- |
| 上 / 下方向键、频道上下键 | 切换选中条目（到头自动循环） |
| 确认 / OK / 中控回车、播放暂停键 | 播放当前选中条目 |
| 点击条目 | 选中并立即播放 |

## 重要：明文 HTTP 说明

列表里部分电台是 `http://` 明文流（例如 `http://hg.537224.xyz:6060/...`）。
Android 9（API 28）起系统会拒绝应用的明文流量，平台的 MediaPlayer 同样会拒绝，
导致这些频道点不动。因此 `hooks/patch_manifest.py` 会在打包时
给 manifest 注入 `android:usesCleartextTraffic="true"`，不要删除这个钩子。

## 打包与安装

使用方法：
1. Fork 本仓库
2. 上传代码
3. GitHub Actions 自动生成 APK
4. 下载并安装到安卓车机

## 本地测试

    python tests/logic_test.py

覆盖范围：列表解析（M3U / 纯 URL / 名称,URL / 去重）、按键映射（SDL 与安卓原生键码）、
选中项循环与播放标记。测试用 stub 顶替 kivy 与 android，无需安装依赖。
